# Pizzería Admin — app web adaptable

No requiere Android Studio. Incluye registro de ventas, pagos en efectivo/transferencia, productos y precios por tamaño, apertura de caja, gastos, reportes CSV para Excel y copia/restauración JSON.

## Para abrirla
- Descomprime el ZIP y abre `index.html` para probar la interfaz.
- Para instalarla como aplicación y tener modo sin conexión, publícala en un hosting HTTPS (GitHub Pages, Netlify o hosting propio).
- En Android abre la dirección en Chrome → menú ⋮ → **Añadir a pantalla principal** o **Instalar aplicación**.
- En computador abre la misma dirección en Chrome/Edge.

## Datos
Los datos se guardan localmente en el navegador. Esta versión NO sincroniza automáticamente la información entre el celular y el computador. Para compartir una sola base de datos entre varios equipos se debe agregar una base de datos en la nube y acceso de usuario.

Los precios iniciales son ejemplos; cámbialos en Productos. Los archivos CSV descargados desde Reportes se pueden abrir en Excel. Descarga respaldos JSON con regularidad.
